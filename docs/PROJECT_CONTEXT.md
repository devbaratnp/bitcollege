# BIT campus concept implementation

Institutional public website redesign, new standalone Site. The approved visual is the second displayed image: Campus / Institutional Confidence.

Static, anonymous, single institution. No payments, accounts, database, uploads or administrative CMS requested. Direct phone/email contact and email composition are the admissions workflow. College sources, original logo and campus/student photos are reused. The current bit.edu.np production site is not modified.

Stack: semantic static HTML, shared CSS, small vanilla JavaScript, locally hosted Barlow Condensed and Inter, Remix Icon 4.6.0. Hosting: Sites static dist. Primary users: students, parents and current learners. Mobile navigation, searchable archive and accessible photo lightbox.
